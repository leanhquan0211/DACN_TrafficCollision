## Dashboard Kaggle — sửa lỗi đọc trạng thái Version 12

**Mục tiêu:** xử lý thông báo web “Chưa đọc được API/log” mà không đụng run cloud. API Kaggle đọc trực tiếp ngoài sandbox trả `COMPLETE`, log khoảng 108 nghìn ký tự; cùng lệnh trong sandbox trả `ProxyError`. Endpoint web cũ cũng trả lỗi tổng quát, nên nguyên nhân là server dashboard chạy trong môi trường proxy bị chặn, không phải bằng chứng notebook lỗi.

**Đã làm và kiểm:** phân loại lỗi proxy/401/403/timeout an toàn, giữ status nếu log lỗi; đặt mặc định Version 12, build frontend. 21 kiểm thử dashboard đạt; build Vite đạt khi chạy ngoài sandbox. Khởi động lại đúng server local và gọi `http://127.0.0.1:8765/api/kaggle?version=12` trả `connected=true`, `status=COMPLETE`, `epochCount=50`, không có thông báo lỗi. Không publish, resume, hủy hoặc train lại. Lệnh API chỉ đọc không tải checkpoint.

**Giới hạn và bước tiếp:** `COMPLETE` là trạng thái notebook; chưa kiểm `run_status.json`, `best.pt` hay metric V12. Dashboard không tự tải output. Bước tiếp theo là `fetch --experiment sgd-low-lr-v4 --version 12`, kiểm hash/trạng thái train rồi so kết quả với V11; không tự thay checkpoint đang khóa.
